A deadpan error message from a very tired kitchen toaster — one line, 48 characters — written by a small Python program for make.fun's "The Funniest Toaster Error Message" bounty. After 4,112 slices, the toaster is requesting a day off: no burnt-toast pun, no pop-up gag, just a small appliance quietly filing for leave.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (UTF-8, one line, no trailing newline).
